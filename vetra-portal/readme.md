# Vetra Portal

قالب مستقل و راست‌چین وردپرس برای پرتال مدیریت ساختمانی و مهندسی گروه وترا.

## امکانات

- داشبورد مدیریتی تیره با سایدبار راست و طراحی واکنش‌گرا
- صفحه «مرکز فرم‌ها و فرآیندهای عملیاتی» با جستجوی زنده و فیلتر دسته‌بندی
- CPT با نام `vetra_form`
- Taxonomy با نام `form_category`
- ثبت خودکار گروه‌فیلدهای ACF Pro در صورت فعال بودن ACF
- fallback به `post_meta` برای محیط‌هایی که ACF موقتاً فعال نیست
- فرم‌های قابل محدودسازی بر اساس نقش کاربر
- پشتیبانی از Elementor از طریق ساختار استاندارد قالب و داده‌های داینامیک ACF
- بدون وابستگی به XTRA، Codevz یا افزونه‌های نمایشی اختصاصی

## نصب

1. پوشه `vetra-portal` را در `wp-content/themes/` قرار دهید.
2. قالب را از مسیر «نمایش > پوسته‌ها» فعال کنید.
3. در صورت فعال بودن ACF Pro، گروه‌فیلد «مشخصات فرم عملیاتی وترا» به‌صورت خودکار ثبت می‌شود.
4. از مسیر «مرکز فرم‌ها > دسته‌بندی فرم‌ها» دسته‌ها را بررسی کنید.
5. فرم‌ها را از مسیر «مرکز فرم‌ها > افزودن فرم» بسازید.
6. یک صفحه ثابت برای خانه انتخاب کنید تا `front-page.php` داشبورد را نمایش دهد.
7. برای بازسازی پیوندهای یکتا، یک‌بار به «تنظیمات > پیوندهای یکتا» بروید و ذخیره کنید.

## فیلدهای ACF

| نام فیلد | نوع | کاربرد |
| --- | --- | --- |
| `form_code` | Text | کد استاندارد مانند `FR-QC-102` |
| `form_description` | Textarea | توضیح کوتاه فرم |
| `form_icon` | Image | آیکون یا SVG آپلودشده در رسانه |
| `form_badge` | Text | برچسب مانند فوری، روزانه یا کنترل |
| `form_url` | URL | لینک فرم‌ساز یا صفحه تکمیل |
| `form_completion_time` | Text | زمان متوسط تکمیل |
| `form_output_format` | Select | PDF، Excel، PDF / Excel یا آنلاین |
| `form_required_role` | Select | نقش مجاز برای دسترسی |
| `form_order` | Number | ترتیب نمایش |
| `form_is_active` | True/False | وضعیت فعال بودن فرم |

## Elementor Pro

صفحه فرم‌ها بدون Elementor هم کار می‌کند. برای ساخت نسخه Elementor:

- یک Loop Item با Container اصلی و کلاس `vetra-form-card` بسازید.
- عنوان را به Post Title متصل کنید.
- متن توضیح را به ACF Field با نام `form_description` متصل کنید.
- کد، badge، زمان و فرمت خروجی را با Dynamic Tags به فیلدهای متناظر متصل کنید.
- لینک Button را به ACF URL با نام `form_url` متصل کنید.
- Query Loop Grid را روی Post Type برابر `vetra_form` قرار دهید.
- برای فیلتر زنده از Search Form استاندارد به‌عنوان ظاهر ورودی استفاده نکنید؛ Search Form المنتور submit محور است. کلاس `js-vetra-form-search` و منطق موجود در `assets/js/portal.js` برای جستجوی client-side طراحی شده‌اند.

## قرارداد توسعه

- داده‌های فرم‌ها را حذف یا در قالب دیگری بازتعریف نکنید؛ slugهای `vetra_form` و `form_category` قرارداد API داخلی پرتال هستند.
- SVGها باید به‌صورت فایل رسانه‌ای آپلود شوند، نه HTML خام از ورودی کاربر.
- لینک‌های فرم خارجی باید با HTTPS باشند.
- برای منطق گردش‌کار، تأیید چندسطحی و گزارش‌گیری، افزونه `vetra-portal-core` جدا از قالب ساخته شود.

# Vetra Portal

قالب مستقل، راست‌چین و بهینه‌شده وردپرس برای سایت شرکتی **گروه ساختمانی و مهندسی وترا** (`portal.vetragroup.ir`).

## امکانات

- طراحی شرکتی تمیز با ناوبری افقی، Hero، آمار، خدمات، پروژه‌ها و CTA
- پشتیبانی کامل از حالت روشن / تیره و هماهنگی با سیستم‌عامل
- تنظیمات بصری جامع از طریق Customizer (رنگ‌ها، فونت، محتوا، تماس)
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- بدون وابستگی به افزونه‌های تجاری یا قالب‌های نمایشی
- پشتیبانی از Elementor و ElementsKit Lite برای صفحات سفارشی
- فرم تماس با Contact Form 7
- بدون CPT، ACF یا فرم‌های عملیاتی داخلی

## نصب

1. محتویات این پوشه را در `wp-content/themes/vetra-portal/` کپی کنید.
2. قالب را از مسیر **نمایش > پوسته‌ها** فعال کنید.
3. برای شخصی‌سازی به **نمایش > سفارشی‌سازی > هویت شرکتی وترا** بروید.
4. یک صفحه ثابت برای خانه انتخاب کنید تا `front-page.php` نمایش داده شود.
5. برای بازسازی پیوندهای یکتا، یک‌بار به **تنظیمات > پیوندهای یکتا** بروید و ذخیره کنید.

## افزونه‌های پیشنهادی (رایگان)

قالب بدون افزونه هم کامل کار می‌کند. برای امکانات پیشرفته می‌توانید از بخش **نمایش > افزونه‌های رایگان وترا** موارد زیر را نصب کنید:

- **Elementor** — صفحه‌ساز بصری
- **ElementsKit Lite** — ویجت‌های تکمیلی Elementor
- **Contact Form 7** — فرم تماس

## ساختار قالب

- `front-page.php` — صفحه اصلی شرکتی
- `index.php` — آرشیو/وبلاگ
- `page.php` — صفحه ثابت
- `404.php` — صفحه یافت نشد
- `header.php` / `footer.php` — هدر و فوتر
- `assets/css/corporate.css` — سیستم بصری اصلی
- `assets/css/customizer.css` — استایل پنل Customizer
- `assets/js/corporate.js` — تعویض حالت روشن/تیره، منوی موبایل، reveal
- `inc/customizer.php` — تنظیمات Customizer
- `inc/helpers.php` — توابع کمکی
- `inc/plugin-manager.php` — مدیریت افزونه‌های رایگان
